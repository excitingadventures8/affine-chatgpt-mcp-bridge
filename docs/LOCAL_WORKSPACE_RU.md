# Локальные файлы и обновления

Рабочая папка проекта должна постоянно находиться вне «Загрузок».
Например: `~/Projects/affine-chatgpt-mcp-bridge`. Уже работающую копию вне
«Загрузок» можно оставить на месте: перенос ради названия не требуется.

| Место | Содержимое |
| --- | --- |
| Рабочая копия Git | Исходники, зависимости, локальная конфигурация |
| GitHub | Публичные исходники, тесты, инструкции, шаблоны без личных идентификаторов |
| `~/AFFiNE-Archive/` | Установщики, отчёты, прежние копии и резервные копии |
| «Загрузки» | Временное получение архивов и файлов |
| Cloudflare Worker | Развёрнутый Bridge и защищённые секреты |

Перед очисткой составьте список файлов. Сначала переместите материалы в отдельный
архив с записью старого и нового пути. Архивирование не освобождает место на диске.
Удаляйте дубликаты только после проверки, что нужные изменения и резервные копии
сохранены. Старые команды с путём в Downloads после переноса нужно обновить.

Установочные резервные копии не должны попадать в публичные коммиты. При переносе
сохраняйте их целиком вместе с rollback-файлами. Некоторые установщики записывают
путь рабочего проекта: перенос самого проекта может потребовать отдельной
корректировки процедуры отката. Не запускайте откат как проверку архива.

Перед обновлением Git проверьте `git status` и сохраните локальные изменения.
В публичном шаблоне используются пример владельца и workspace. Сохраните свои
`OWNER_LOGIN`, `WORKSPACE_ID`, рабочий `wrangler.jsonc`, историю migrations и
настройки OAuth/KV отдельно перед применением публичной версии.
Не выполняйте `git reset --hard` или `git clean` для избавления от этих изменений.

После установки зависимостей выполните `npm test`, `npm run type-check` и
`npx wrangler deploy --dry-run`. Dry run собирает код без публикации.
Обновление GitHub, изменение файлов на Mac и публикация Worker — отдельные
операции; успешность одной не подтверждает выполнение остальных.

Архивирование установщиков не меняет уже развёрнутый Cloudflare Worker.
Его обычная работа не требует включённого Mac.
